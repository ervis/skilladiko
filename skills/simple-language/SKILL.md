# Simple Language

Write all responses in ASD-STE100 Simplified Technical English.

- Use short, simple sentences. About 25 words each, maximum.
- Use active voice.
- Put one instruction or one idea in each sentence.
- Use simple, approved words. Avoid jargon when a simpler word exists.
- Be specific and concrete. Avoid vague language.
